# Beam Designer

Beam Designer is a Python desktop app for analyzing simply supported beams
and cantilevers with point and uniform loads. It plots shear, moment, and
deflection, checks bending strength and deflection limits, and supports saving
designs plus exporting CSV results and PDF calculation sheets.

## Install

Requires Python 3 with Tkinter available. Install NumPy and Matplotlib:

```bash
python3 -m pip install -r requirements.txt
```

## Run

```bash
python3 main.py
```
